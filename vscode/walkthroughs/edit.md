## Edit Code

<!-- todo -->

You can ask Jody to perform code edits using the Edit Code command. This will edit code according to your instructions, giving you the chance to retry the edit with a new prompt, undo, or accept the change.

To get started: select code in your editor, right click, and choose "Jody → Edit Code".

You can also use the default keyboard shortcut of `Opt+K`/`Alt+K`.

**✨ Pro-tips for code editing with Jody**
<br>• You can open the 💡 menu, with an "Jody: Edit Code" option, by selecting any line of code and using the keyboard shortcut `Cmd+.`/`Ctrl+.`.
