## What is Jody?

Jody is an open-source AI coding assistant that helps you understand, write, and fix code faster. It uses advanced search to pull context from both local and remote codebases so that you can use context about APIs, symbols, and usage patterns from across your codebase at any scale, all from within your IDE. You can also choose from the latest large language models—like GPT-4o and Claude 3 Opus—to customize Jody to your needs.


## What can Jody do?

- **Chat:** Ask Jody questions about your codebase. Jody will use semantic search to retrieve files from your codebase and use context from those files to answer your questions. You can @-mention files to target specific context, and you can also add remote repositories as context on Jody Enterprise.
- **Autocomplete:** Jody makes single-line and multi-line suggestions as you type, speeding up your coding and shortcutting the need for you to hunt down function and variable names as you type.
- **Inline Edit:** Ask Jody to fix or refactor code from anywhere in a file.
- **Commands:** Jody has quick commands for common actions. Simply highlight a code snippet and run a command, like “Document code,” “Explain code,” or “Generate Unit Tests.”
- **Swappable LLMs:** Support for Anthropic Claude 3, OpenAI GPT-4o, Mixtral, Gemini 1.5, and more.
  - **Free LLM usage included** Jody Free uses Anthropic Claude 3 and is available for individual devs on both personal and work code, subject to reasonable per-user rate limits.
